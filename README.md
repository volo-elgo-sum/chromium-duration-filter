# 3時間超の動画を非表示

指定された動画一覧の長さ表示を読み取り、`3:00:00` より長い動画のカードを隠す Chromium 拡張です。`3:00:00` ちょうどは表示されます。ページ内で後から追加されたカードも処理します．

## インストール

1. Chromium で `chrome://extensions` を開く．
2. 「デベロッパー モード」を有効にする．
3. 「パッケージ化されていない拡張機能を読み込む」を押し、この `chromium-duration-filter` フォルダーを選ぶ．

HTTP / HTTPS の全サイトで動作します。指定されたクラス構成に合う一覧だけが対象です．  
動画の絞り込みの際に使用してください．  
2時間と4時間の間には大きな壁があるはずです．  
なるべく課金しませう．
